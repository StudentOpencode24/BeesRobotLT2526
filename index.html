1. Шасси и База

Демонстрация работы механумной базы

Наша база создана для максимальной проходимости. Гибридная конструкция из профилей GoBilda и Tetrix.

Ключевые особенности:

  • Колеса: Самостоятельно напечатанные механум-колеса (Ø14 см) для легкого заезда на пандус.
  • Привод: Моторы GoBilda с энкодерами.
  • Навигация: 2 внешних одометра GoBilda + внутренние энкодеры моторов.
  • Стенки: Фанера лазерной резки для жесткости.

Программное обеспечение

Библиотека RoadRunner позволяет строить точные сплайновые траектории и перемещаться по координатам поля, компенсируя пробуксовку колес.

2. Подъемник (Башня)

Работа цепной передачи и фиксация крюка

Центральная башня с цепным приводом. Крюк цепляется за пандус и приподнимает робота.

Техническая часть

  • Привод: Мотор Tetrix + понижающая передача (шестерня Ø3.8 см).
  • Передача: Металлическая цепь.
  • Крюк: 3D-печатный уголок с оконным уплотнителем для сцепления.
  • Направление: Линейная направляющая.

💡 Инженерный урок

Проблема: Сгорание мотора на Робосибе из-за отсутствия ограничителей и ошибки порта.

Решение: Программное удержание (Hold Mode). Если кнопки не нажаты, подается малое напряжение для фиксации позиции, предотвращая падение под весом робота.

3. Захват и Манипулятор

Работа захвата плиток и наведение по камере

3.1 Слайдер и Захват

Слайдер: Телескопический механизм на базе профилей, приводимый в движение отдельным мотором через ременную/зубчатую передачу (уточнить тип, если важно, иначе оставить общим). Обеспечивает выдвижение захвата за пределы робота.

Захват: Активная клешня, управляемая сервоприводами. Специальные накладки обеспечивают надежный захват игровых элементов (плиток).

3.2 Компьютерное зрение (AprilTags)

Камера распознает метки AprilTag на поле. Алгоритм вычисляет смещение робота относительно цели и автоматически корректирует угол поворота шасси и положение слайдера для идеального позиционирования перед сбросом элемента.

4. Вспомогательные ролики (Panda-Lift)

Механизм преодоления пандуса (24°)

Техническое описание

Уникальный механизм для заезда на крутой (24°) и скользкий пандус.

  • Принцип действия: Рычажная система опускает заднюю ось с двумя дополнительными колесами, приподнимая основные колеса над полом.
  • Привод: Мощные сервоприводы (30 кг/см) максимально прижимают колеса к поверхности для увеличения трения.
  • Колеса: Ø75 мм, пластик PETG, оклеены оконным уплотнителем для лучшего сцепления.
  • Ось: Стальная, Ø6 мм, закреплена в хабах Tetrix.

Программное обеспечение

Реализованы функции rampMove() и stopRampMove(), которые синхронизируют работу сервоприводов опускания с подачей мощности на основные моторы шасси.

5. Программное обеспечение

Архитектура кода построена на принципах ООП для модульности и удобства отладки.

Структура классов

Выделен отдельный класс RobotHardware для инициализации устройств и базовых действий:

  • aprilTagCorrection() - коррекция курса по камере.
  • rampMove() / stopRampMove() - управление механизмом пандуса.
  • getAngle() / resetAngle() - работа с IMU (гироскопом).
  • setPlateStateToFull/Partial() - управление состоянием захвата.
  • upTheRamp() - автоматизированный алгоритм заезда.

Режимы работы

  • Autonomous: Перемещение по координатам (RoadRunner). Полная автоматика сбора и выгрузки.
  • TeleOp: Полуавтоматические режимы. Одно нажатие запускает цикл: "Наведение -> Захват -> Возврат".
  • Dashboard: Визуализация состояния робота и переменных в реальном времени через браузер.
