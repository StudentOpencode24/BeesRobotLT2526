1. Шасси и База

Демонстрация работы механумной базы

База для максимальной проходимости. Гибрид профилей GoBilda и Tetrix.

Особенности:

  • Колеса: Печатные механумы Ø14 см.
  • Привод: Моторы GoBilda с энкодерами.
  • Навигация: 2 одометра + энкодеры моторов.

Программы

RoadRunner для точных траекторий и компенсации пробуксовки.

2. Подъемник (Башня)

Работа цепной передачи и крюка

Центральная башня. Крюк цепляется за пандус и приподнимает робота.

Техника:

  • Привод: Мотор Tetrix + шестерня Ø3.8 см.
  • Передача: Металлическая цепь.
  • Крюк: 3D-печать + оконный уплотнитель.

💡 Инженерный урок

Проблема: Сгорание мотора из-за ошибки порта.

Решение: Программное удержание (Hold Mode) для фиксации позиции без перегрева.

3. Захват и Манипулятор

Работа захвата и сервоприводов

Двухступенчатый манипулятор для сбора образцов.

Конструкция:

  • Основание: Вращение на 360° (сервопривод).
  • Плечо: Подъем/опускание (сервопривод).
  • Захват: Две независимые челюсти.

Управление:

Игрок управляет джойстиком: левый стик — поворот/наклон, правый — захват.

4. Роликовая система

Тестирование роликовой системы

Система для забора образцов с поверхности.

Характеристики:

  • Мотор: GoBilda с редуктором.
  • Ролики: Силиконовые, для лучшего сцепления.
  • Регулировка: Высота подбирается под рельеф.

💡 Инженерный урок

Проблема: Проскальзывание на гладкой поверхности.

Решение: Замена роликов на силиконовые с протектором.

5. Программное обеспечение

Автономная навигация и точное управление.

Технологии:

  • RoadRunner: Планирование траекторий.
  • OpenCV: Распознавание Apriltag.
  • PID-регуляторы: Для плавного движения.

Пример кода (RoadRunner):

TrajectorySequence trajectory = drive.trajectorySequenceBuilder(startPose) .forward(30) .turn(Math.toRadians(90)) .forward(20) .build(); drive.followTrajectorySequence(trajectory);

Камера и Vision:

Распознавание маркеров Apriltag для точной навигации.

Структура проекта:

  • TeleOp: Ручное управление.
  • Auto: Автономные режимы.
  • Hardware: Конфигурация устройств.
