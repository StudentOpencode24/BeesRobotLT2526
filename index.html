2. Шасси и База

Конструктив выполнен из алюминиевых профилей GoBilda 1120/1121 Series и уголков Tetrix. Внешний корпус — легкая фанера.

Ключевые особенности:

  • Колеса: Самостоятельно напечатанные механумы Ø14 см (ABS + резина).
  • Одометрия: 2 датчика goBilda 4-Bar Odometry Pod (Ø32мм) для точного позиционирования.
  • Навигация: Библиотека Road Runner строит траектории на основе сплайнов, а PID-регуляторы корректируют движение в реальном времени.

3. Подъемник (Рампа)

Конструкция:

Вертикальный профиль Tetrix с цепным приводом. Мотор TETRIX MAX через понижающую передачу и шестерню (Ø3.8 см) вращает цепь. Крюк с оконным уплотнителем движется по линейной направляющей, исключая перекосы.

Работа над ошибками:

В первой версии управление осуществлялось кнопками без ограничителей, что привело к сгоранию мотора на соревнованиях "РобоСиб".

Решение: Реализована функция stopAndHold(), которая подает небольшое напряжение для удержания веса робота, когда кнопка не нажата.

public void stopAndHold(double holdPower) {
    liftMotor.setPower(holdPower); // Удержание позиции
}

public void lift() {
    liftMotor.setPower(0.8);
}

4. Система заезда на пандус

Принцип действия:

Для гарантированного заезда на пандус (24 градуса) используется система опускающихся вспомогательных колес.

  • Механика: Сервоприводы (30 кг) через систему рычагов опускают ось с двумя колесами Ø75 мм.
  • Физика: Задние колеса робота приподнимаются, вес перераспределяется на переднюю ось.
  • Сцепление: Колеса оклеены оконным уплотнителем для максимального трения со скользкой поверхностью пандуса.

5. Захват и Зрение

Механизм:

Двухсекционный слайдер на алюминиевых направляющих. Привод — мотор goBilda Yellow Jacket (26.9:1) с системой "катушка-нить".

Захват: Два сервопривода на 25 кг обеспечивают жесткое удержание плиток без перекосов.

AprilTag Навигация:

Камера Logitech C615 распознает метки. Функция getAprilTagCorrection вычисляет смещение (X, Y) и корректирует траекторию робота перед выгрузкой элемента.

// Пример коррекции по метке
Vector2d correction = aprilTag.getOffset();
robot.drive.strafeTo(correction);

6. Программное обеспечение

Архитектура (Java / Android Studio)

Код написан с использованием компонентного подхода. Каждый механизм (шасси, лифт, захват) вынесен в отдельный класс для удобства чтения и отладки.

  • RoadRunner: Построение сложных траекторий (сплайны) с учетом ускорений.
  • PID-регуляторы: Для точного удержания углов и позиций.
  • FTC Dashboard: Для мониторинга переменных в реальном времени.

Полный код доступен в нашем GitHub репозитории.

Автономный режим (Пример)

// Инициализация траектории
Actions.runBlocking(
    robot.drive.actionBuilder(beginPose)
        .strafeToConstantHeading(pos.get(1).position)
        .waitSeconds(0.5)
        .strafeToConstantHeading(new Vector2d(-58.8, 28))
        .build()
);

// Действие с лифтом
robot.lift.lift();
sleep(liftTime);
robot.lift.stopAndHold(holdPower);
